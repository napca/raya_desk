# Desk UI refresh — 2026-11-08

Implemented in the existing `raya_desk` app; Frappe and ERPNext core source files were not changed.

## Changes

- Preserve the native ERPNext and Framework launcher icons. Use the Raya mark for Raya and the organisation header only.
- Give the launcher a translated heading, application cards and responsive spacing. Suppress the contextual assistant on the launcher and setup wizard.
- Refine the shared Desk header, sidebar, list filters, empty list, labels, input borders, section spacing and child-table headings. Cover both legacy `.btn` and the installed version's Espresso `.es-button` controls.
- Improve muted-text contrast and focus indicators. Keep RTL/LTR assets generated by Frappe; respect the user's selected language rather than forcing every user to Persian.
- Give the assistant a named microphone action, accessible icon labels, a bounded composer and a single visible entry point while the panel is open.
- Add a heading and bounded input to the dashboard's command area; keep its state label in sync with the same assistant instance. Support keyboard activation of funnel links. Compact the funnel when all readable metrics are zero, without confusing zero with lack of permission. Reflow funnel steps on small screens.
- Add Persian translations for setup, common list/form actions and visible onboarding choices. Keep currency explicit in sales metric headings without oversized currency suffixes wrapping onto a second line.
- Scope setup-card padding separately so native slide section styles cannot put labels against the card edges. Use the native desktop lifecycle event for the launcher heading; no polling or DOM mutation observer.

## Limits and deployment

This is a source and local-development change. The already-running staging image and any remote production server are unchanged. Commit these changes in the **raya_desk app's own Git repository** (the outer Docker repository ignores the development bench), build a new custom image containing that app revision, and deploy it using the repository's release process. Do not edit generated bundles or copy them into production containers manually.

Real STT/LLM services and a real microphone were not tested or connected. Submit, cancel, amend, print, file upload and every ERPNext DocType have not been exercised end to end. Some upstream translation strings, Gregorian date pickers and third-party reports remain outside this UI pass. The changes do not convert stored dates or financial values.

The temporary QA web container was used only for browser review; the separate QA site/database is retained, with scheduler disabled. The normal development web service remains available on port 8000.
